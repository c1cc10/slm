01

Scaled Dot-Product Attention

Il meccanismo fondamentale. Ogni token interroga tutti gli altri tramite tre proiezioni — Query, Key e Value — e ottiene una rappresentazione arricchita dal contesto.

Formula

Scaled Dot-Product Attention
$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

Il denominatore $\sqrt{d_k}$ scala il prodotto scalare: senza di esso, con $d_k$ grande, i valori diventano enormi e il softmax satura verso 0 e 1, rendendo i gradienti quasi nulli.

Implementazione

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = torch.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights
02

Causal Mask

Durante il training, il modello conosce l'intera sequenza. La causal mask gli impedisce di "barare" guardando i token futuri: il token in posizione $i$ può vedere solo le posizioni $0 \ldots i$.

Matrice triangolare inferiore
$$M_{ij} = \begin{cases} 1 & \text{se } j \leq i \\ 0 & \text{se } j > i \end{cases}$$
Perché −∞? Sostituiamo 0 con $-\infty$ negli score prima del softmax. Il softmax calcola $e^{-\infty} = 0$, quindi quelle posizioni ricevono peso nullo senza destabilizzare i gradienti.
seq_len = 4

M =
  [1, 0, 0, 0]  ← token 0: vede solo sé
  [1, 1, 0, 0]  ← token 1: vede 0,1
  [1, 1, 1, 0]  ← token 2: vede 0,1,2
  [1, 1, 1, 1]  ← token 3: vede tutto
03

Multi-Head Attention

Invece di una singola attention, si eseguono $h$ attention parallele su sottospazi di dimensione $d_k = d_\text{model}/h$. Ogni testa può specializzarsi su un tipo diverso di relazione.

Multi-Head Attention
$$\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\, W^O$$ $$\text{head}_i = \text{Attention}(Q W_i^Q,\; K W_i^K,\; V W_i^V)$$
ParametroRuoloShape
$W_i^Q, W_i^K, W_i^V$Proiezioni per testa $i$$(d_\text{model},\, d_k)$
$W^O$Proiezione output$(d_\text{model},\, d_\text{model})$
$d_k$Dimensione per testa$d_\text{model} / h$
04

Positional Encoding

Il Transformer elabora tutti i token in parallelo: senza un segnale di posizione esplicito, "gatto mangia topo" e "topo mangia gatto" sarebbero indistinguibili. La codifica sinusoidale inietta questo segnale sommando un vettore all'embedding di ogni token.

Sinusoidal Positional Encoding
$$PE_{(pos,\, 2i)} = \sin\!\left(\frac{pos}{10000^{\,2i/d_\text{model}}}\right)$$ $$PE_{(pos,\, 2i+1)} = \cos\!\left(\frac{pos}{10000^{\,2i/d_\text{model}}}\right)$$

$pos$ è la posizione nella sequenza, $i$ è l'indice della dimensione. Le frequenze decrescenti creano un "codice binario continuo": le dimensioni basse variano lentamente (distinguono posizioni lontane), quelle alte variano rapidamente (distinguono posizioni vicine).

05

Feed-Forward Network

Dopo l'attention, ogni token passa attraverso una rete fully-connected applicata indipendentemente e identicamente a ogni posizione. L'attention aggrega informazioni tra token; il FFN "ragiona" su ogni token individualmente — è qui che risiede gran parte della capacità memorizzativa.

Position-wise Feed-Forward
$$\text{FFN}(x) = \text{GELU}(x W_1 + b_1)\, W_2 + b_2$$

Per convenzione $d_{ff} = 4 \times d_\text{model}$: il FFN proietta in uno spazio più ampio, applica la non-linearità, poi comprime. GELU è preferito a ReLU nei transformer moderni per la sua smoothness.

06

Layer Normalization

Normalizza le attivazioni lungo la dimensione delle feature (non del batch), stabilizzando la scala dei valori durante il training.

Layer Normalization
$$\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \varepsilon}} \cdot \gamma + \beta$$

$\mu$ e $\sigma^2$ sono media e varianza calcolate sull'ultimo asse (le feature). $\gamma$ e $\beta$ sono parametri learnable che permettono al modello di riscalare e shiftare le attivazioni normalizzate. $\varepsilon \approx 10^{-5}$ evita la divisione per zero.

07

Residual Connection & Pre-Norm

Le residual connection creano un canale diretto attraverso i layer, risolvendo il problema del vanishing gradient nelle reti profonde: il gradiente può fluire direttamente senza attraversare le trasformazioni.

Pre-Norm (architettura GPT-2 / LLaMA)
$$x \leftarrow x + \text{Attention}\!\left(\text{LN}(x)\right)$$ $$x \leftarrow x + \text{FFN}\!\left(\text{LN}(x)\right)$$
Pre-Norm vs Post-Norm. L'articolo originale ("Attention is All You Need", 2017) usava Post-Norm: $x \leftarrow \text{LN}(x + \text{Sublayer}(x))$. I modelli moderni (GPT-2 in poi) usano Pre-Norm: più stabile durante il training, non richiede warm-up del learning rate prolungato.

Il Blocco Transformer Completo

Tutti i componenti assemblati. Il GPT è uno stack di $N$ di questi blocchi preceduto da un embedding layer e seguito da una proiezione sul vocabolario.
